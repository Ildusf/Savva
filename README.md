# Savva Coffee — сайт кофейни

Статический одностраничный сайт (HTML + CSS + JS, без сборки).

## Структура

```
savva/
├── index.html      — разметка всех секций
├── css/style.css   — стили (палитра из меню: оливковый #66714f + кремовый #e6d4b4)
└── js/main.js      — данные меню (EN/AR, цены, калории), переключатель языка, вкладки, статус «открыто/закрыто»
```

## Как открыть

Просто откройте `index.html` в браузере или положите папку на любой хостинг
(Netlify, Vercel, GitHub Pages, обычный хостинг с FTP).

## Что заменить перед публикацией

1. **Фотографии.** Сейчас стоят стоковые фото с Unsplash (ссылки в `index.html`, атрибут `src`).
   Замените их на реальные фото кофейни из Instagram — положите файлы в папку `img/`
   и укажите путь, например `img/hero.jpg`.
2. **Логотип.** Кружок с надписью SAVVA нарисован шрифтом. Если есть векторный логотип,
   вставьте `<img>` внутрь `<a class="brand">` вместо `<span class="roundel">`.
3. **Ссылки «Privacy» и «Terms»** в подвале ведут на `#` — добавьте страницы или удалите.
4. **Цены и позиции** меняются в `js/main.js`, объект `MENU`. Переводы интерфейса — объект `I18N`.
